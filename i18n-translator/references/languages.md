# Languages

Default base file: `en.json`.

Common target language codes from the Flat Copilot i18n translator:

- `ar` - Arabic
- `bn` - Bengali
- `de` - German
- `es` - Spanish
- `fr` - French
- `hi` - Hindi
- `id` - Indonesian
- `it` - Italian
- `ja` - Japanese
- `ms` - Malay
- `pa` - Punjabi
- `pt` - Portuguese
- `ru` - Russian
- `ta` - Tamil
- `te` - Telugu
- `th` - Thai
- `tr` - Turkish
- `ur` - Urdu
- `vi` - Vietnamese

Accept custom language codes in lowercase ISO-like form such as `ko`, `nl`, or region form such as `pt-br` when the project already uses that naming convention.
